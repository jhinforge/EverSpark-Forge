# 分布式模型与第三方模型服务

在机器页面选择 Forge 节点后，Storage 的模型直链下载与云盘拉取按资源类型定位：

| 资源 | 目标 |
| --- | --- |
| Checkpoint、扩散模型、LoRA、VAE | 当前选择的 Image Forge 节点 |
| GGUF、Ollama 云盘模型 | 当前选择的 Concept Forge 节点 |
| OpenAI Compatible 模型服务 | 主机保存连接配置并直接调用服务，无需下载模型或部署 Concept 节点 |

下载在目标节点执行，模型数据无需先经过主机。GGUF 下载完成后，在目标节点本机
导入 Ollama。没有选择对应节点时，系统拒绝该类下载，不会回退到主机。
Storage 显示下载目标；任务开始后固定目标节点，进度查询、取消和直链重试沿用
原节点。切换节点不会把已创建的下载任务迁移到另一台机器。

云盘来源与目录映射仍由主机管理。开始云盘拉取时，系统将当前 rclone 配置与映射
发送到目标节点的私有配置快照；快照文件权限为 0600，任务进度不包含凭据。
节点首次使用云盘时会按需安装 rclone。不同配置快照相互独立，修改来源配置
不会覆盖正在传输任务使用的配置。备份、恢复与角色数据仍在主机侧执行。

创作页的 Checkpoint、LoRA、VAE 和工作流列表来自当前 Image Forge 节点；语言
模型列表来自当前 Concept 节点的 Ollama，或所选 API 连接的模型 ID。下载完成后
刷新资源列表；切换节点清除已添加的 LoRA，并重新校验其他选择。
LoRA 注入仍取决于所选工作流能力，模型与工作流的兼容范围沿用各 Image 引擎。
远端绘图引擎的安装、启用属于节点部署管理，创作页只选择和使用。

使用第三方服务时，先选择 Image Forge 节点，再在模型服务页面保存并测试
OpenAI Compatible 连接，在创作页选择该服务与模型。也可将该服务设置为默认；
默认设置在更换 Forge 节点、重建运行环境后保留。请求与 API Key 留在主机侧，
不会转发给远端 Concept 节点。请求显式选择 Ollama 时仍需要在线 Concept 节点。

更新后，请同时更新主机与目标节点的分支源码。节点模型传输服务在首次操作时
启动，只监听本机回环地址，并由私有令牌验证访问；Envoy 只开放指定模型操作。
传输服务可以跨 Envoy 重连与主机运行环境切换继续执行。节点重启或传输服务退出
会丢失内存中的任务状态；查询会报告不可用，不会自动重复下载。已下载文件及
直链的断点文件仍在磁盘上，检查节点后可重新提交下载。

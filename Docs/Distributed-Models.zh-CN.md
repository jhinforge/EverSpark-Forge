# 分布式模型与第三方模型服务

在机器页面选择 Forge 节点后，Storage 的模型直链下载与云盘拉取按资源类型定位：

| 资源 | 目标 |
| --- | --- |
| Checkpoint、扩散模型、LoRA、VAE | 当前选择的 Image Forge 节点 |
| GGUF、Ollama 云盘模型 | 当前选择的 Concept Forge 节点 |
| OpenAI Compatible 模型服务 | 主机保存连接配置并直接调用服务，无需下载模型或部署 Concept 节点 |

下载在目标节点执行，模型数据无需先经过主机。GGUF 下载完成后，在目标节点本机
导入 Ollama。没有选择对应节点时，系统拒绝该类下载，不会回退到主机。
Storage 显示下载目标；任务开始后固定目标节点，进度查询、取消和直链重试沿用
原节点。切换节点不会把已创建的下载任务迁移到另一台机器。

云盘来源与目录映射仍由主机管理。开始云盘拉取时，系统将当前 rclone 配置与映射
发送到目标节点的私有配置快照；快照文件权限为 0600，任务进度不包含凭据。
节点首次使用云盘时会按需安装 rclone。不同配置快照相互独立，修改来源配置
不会覆盖正在传输任务使用的配置。备份、恢复与角色数据仍在主机侧执行。

创作页的 Checkpoint、LoRA、VAE 和工作流列表来自当前 Image Forge 节点；语言
模型列表来自当前 Concept 节点的 Ollama，或所选 API 连接的模型 ID。下载完成后
刷新资源列表；切换节点清除已添加的 LoRA，并重新校验其他选择。
LoRA 注入仍取决于所选工作流能力，模型与工作流的兼容范围沿用各 Image 引擎。
远端绘图引擎的安装、启用属于节点部署管理，创作页只选择和使用。

使用第三方服务时，先选择 Image Forge 节点，再在模型服务页面保存并测试
OpenAI Compatible 连接，在创作页选择该服务与模型。也可将该服务设置为默认；
默认设置在更换 Forge 节点、重建运行环境后保留。请求与 API Key 留在主机侧，
不会转发给远端 Concept 节点。请求显式选择 Ollama 时仍需要在线 Concept 节点。

更新后，请同时更新主机与目标节点的分支源码。节点模型传输服务在首次操作时
启动，只监听本机回环地址，并由私有令牌验证访问；Envoy 只开放指定模型操作。
传输服务可以跨 Envoy 重连与主机运行环境切换继续执行。节点重启或传输服务退出
会丢失内存中的任务状态；查询会报告不可用，不会自动重复下载。已下载文件及
直链的断点文件仍在磁盘上，检查节点后可重新提交下载。

## 图片与音频访问

结果查询只返回状态、文件信息与访问 URL，不再提前将图片或 WAV 下载到主机。
图片及音频原件仍保存在生成它们的节点上。

节点首次返回媒体结果时启动私有文件服务，只绑定 Tailscale 地址；访问 URL 带有
一小时有效的文件签名，不公开整个输出目录。浏览器位于同一虚拟局域网时优先
直接读取节点 URL。音频支持 HTTP Range，可拖动播放进度。URL 过期后刷新图库
获取新地址；节点或 Pod 销毁后，未另行保存的文件无法继续访问。

浏览器不能直连、地址加载失败或页面通过 HTTPS 分享时，使用主机流式转发备用
通道。转发复用节点现有的出站连接：一次任务触发一次连续二进制上传，主机使用
有界内存转发给浏览器，不保存原件，也不再逐个 24 KiB 分块发送任务。一次性
转发令牌只交给对应节点；浏览器断开后转发释放。直连请求等待超过十秒也会尝试
备用通道。节点文件服务不会记录签名 URL。

点击“Download outputs ZIP”时，当前 Image 节点才创建图片 ZIP 并流式返回，
节点临时 ZIP 在请求结束后删除；该 ZIP 包含当前 Image 节点的图片，不合并其他
节点或音频。单个 WAV 的下载按钮按需读取音频。原有本地运行的输出打包保留。
首次测试需要同时更新主机与节点源码；查看与下载仍消耗网络带宽。

## 节点下载测速

Linux 节点首次注册成功后，在独立后台进程执行一次 LibreSpeed 下载测速，
无需等待 Forge 部署。下载阶段为 30 秒；首次安装工具、选择测速服务器以及
错开启动需要额外时间。仅测节点到公网测速服务器的下载，不测上传，也不测
节点到主机的速度。测速数据不写入模型目录，不保留下载内容。

机器卡片显示平均下载速度（十进制 MB/s）、测速服务器和时间。
区域已确认且测速服务器位于同一区域时，速度达到 **50 MB/s** 为合格；
低于该值建议更换 Pod，但不自动销毁或禁止部署。
测速失败显示失败，不能当成 0 MB/s 或不合格。结果只代表该测速服务器的线路，
不能保证所有模型站和云盘达到同样速度。

结果保存在节点私有目录的 `bandwidth.json`，经认证心跳回传并保存在主机节点
索引；Agent 重连、重启不会自动重复测速。在线节点的“重新测试下载速度”按钮
可手动重测，正在测速时避免重复启动。手动请求复用 Agent 任务通道，节点正在
执行部署时可能需要等待部署结束后重试。

工具固定为 LibreSpeed CLI **1.0.14**，Linux amd64/arm64 发布包校验 SHA-256 后
安装。采用三个并行下载连接，禁用上传和结果分享；30 秒以 50 MB/s 运行约消耗
1.5 GB 下载流量。`EVERSPARK_NODE_BANDWIDTH=0` 可关闭节点自动测速和手动测速。
首次使用需要同时更新主机与节点，并重启 Agent；既有节点会在更新后的首次
注册时补做一次测速。


区域选择按节点公网出口 IP 的地理定位，以洲级区域（亚洲、欧洲、北美洲、南美洲、
非洲、大洋洲）筛选当前 LibreSpeed 公共服务器列表，再在区域内根据延迟选服。
地理定位通过 HTTPS 查询 ipwho.is，仅用于选服；公网出口位置可能与供应商标注的
物理位置不同。卡片显示区域和出口国家，便于核对。服务器名单中无法确认国家
的条目不参与自动选择。区域未知、本区域没有服务器或服务器不可达时，显示
测速失败及原因，不自动回退到其他区域，也不建议更换 Pod。

旧版缺少区域信息的测速结果仅供参考，不参与 50 MB/s 合格判断；更新并重启
Agent 后会自动补测一次。后续普通重连仍复用新结果，不重复自动测速。

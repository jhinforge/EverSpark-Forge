# 日常使用

首次部署见[首次使用](Getting-Started.zh-CN.md)。本页按当前侧边栏组织操作。

## 创作

讨论模式用于形成和修改角色；生成模式接受本次画面与声音需求。选择图片、音频或图片＋音频模式后，检查对应 Forge 节点和模型服务。明确提供的台词默认保留；翻译或改写应写在需求里。

图片设置包括当前节点提供的工作流、Checkpoint、LoRA、VAE 等。切换节点后重新检查资源；不同工作流的模型与 LoRA 支持范围不同。工作流必须是受支持的 API Format 与相邻清单，普通 ComfyUI UI JSON 不能直接作为已注册工作流使用。

任务列表显示每一步的 Forge、执行节点和状态。当前编排按依赖顺序调用 Forge，不因位于不同机器而自动并行。失败后检查未执行步骤，不要把某一步完成理解为整个请求成功。

## 资产库

- **角色**：选择、使用和查看角色修订；“列表中存在”不等于当前对话已选择。
- **图像／音频**：查看生成历史、播放音频、下载单文件，或分别下载图片与音频 ZIP。
- **数据备份**：下载角色与 Memory 数据 ZIP，或选择有效 ZIP 验证并恢复。恢复后重启主机。

图片 ZIP 与音频 ZIP 各自来自当前对应 Forge 节点，不自动合并不同节点的全部历史。桌面客户端先弹另存为，再直连 Pod 下载；完成后提示实际保存路径。浏览器版按浏览器设置保存。保存输出不等于保存角色、模型或配置，见[数据指南](Runtime-and-Data.zh-CN.md)。

## 计算

“我的机器”负责已有实例、Node、Forge 部署与选择；“租用 GPU”负责报价搜索和租赁；“运行状态”用于查看 Archon 与 Forge 健康状态。Node 心跳在线与 Forge 健康是不同条件。

可选网络测速使用 Ookla 官方 CLI，首次确认在页面完成，不要求手动 SSH；结果是测速服务器线路的参考，不保证云盘或模型站速度。失败不阻止生成。细节见[节点测速](../Legate/Envoy/bandwidth.md)。

## 资源与设置

**资源**负责模型直链下载与云端模型扫描、拉取；下载目标是所选 Image 或 Concept 节点，任务启动后不会随节点切换迁移。Audio 权重由 Audio 部署流程准备，不要将其当作 Image 或 Concept 模型拉取。

**设置**负责模型 API、Vast/Tailscale 和云端存储配置。云端目录可只配置图片或只配置 Concept，见[配置指南](Configuration.zh-CN.md)。
